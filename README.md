# Roblox Tower Defense Framework

A modular Roblox tower defense framework built in Luau.

This repository contains selected code samples from a tower defense project I programmed, focused on gameplay systems and backend architecture.

## Main Systems

- Config-driven units
- Config-driven enemy waves
- Unit placement and upgrades
- Enemy movement and targeting
- Combat and damage handling
- Ability system
- AoE and cone attacks
- Boss and enemy support
- Rewards and currency
- Client/server communication
- Collision and animation logic

## Architecture

The project is structured around reusable modules and configuration files so new units, enemies, waves, and abilities can be added without rewriting the main systems.
